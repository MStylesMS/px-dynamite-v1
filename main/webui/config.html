Runtime Config

Maglock pulse is hard-capped at 400 ms. Keypad codes A–H are independent of the target gram sums. MQTT {"targetCode":"A7D36#","targetWeight":1450} can override the current game without saving over A–H.

Target weights

Gram sums only — order and which same-weight charge (ID05 vs ID07) do not matter. A non-empty sum with no 4-charge combination is rejected (red field). Valid sums show how many unordered 4-charge subsets hit that weight.

Code Entry targets

Safe / keypad codes only. Blank codes still appear in the Live dropdown. Apply + Save stores them (demo: localStorage).

Charge weights

Reed-decoded IDs 1–15, in grams. Changing a weight recalculates which target sums are possible. ID05 and ID07 both default to 250 g, and those two charges count as distinct solutions.
